# Mishkah Website

The marketing site, privacy policy, and support page for [Mishkah](https://github.com/afifaali931/Mishkah---Quran-App), a Quran reader for Android.

Plain static HTML/CSS, no build step — deploy as-is with GitHub Pages.

## Pages

- `index.html` — marketing / landing page
- `privacy.html` — privacy policy (linked from the Play Store listing)
- `support.html` — support page & FAQ (linked from the Play Store listing)

## Deploying with GitHub Pages

Settings → Pages → Source: Deploy from branch → `main` / `/ (root)`.
